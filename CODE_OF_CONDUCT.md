# Contributor Covenant Code of Conduct

We are committed to a welcoming and respectful community.

## Our standards

Be considerate, patient and constructive. Respect different viewpoints and experiences. Accept responsibility for mistakes and work to repair harm. Do not harass people, publish private information, or use sexualized language or imagery in community spaces.

## Scope and enforcement

This applies to project spaces and public interactions when someone represents the project. Report abusive behavior to the project maintainers through a private GitHub contact or security advisory. Maintainers may remove content or restrict participation when needed to protect contributors. They should explain moderation decisions where practical.

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
