# Changelog

Notable changes to nano Agent are recorded here.

## 0.1.0a1 — Unreleased preview

- First alpha of the provider-agnostic personal assistant CLI and private console.
- Includes model providers, tool calling, memory, skills, learning controls, task scheduling, draft approvals, optional LINE and Google integrations, MCP, voice adapters, health checks and guarded code patch proposals.
- Installer supports Linux, macOS, WSL, and native Windows.
- Console includes direct Chat and Dark, Modern, Calm, and Minimal appearance choices across its pages.
- Live provider, Google, LINE and MCP interoperability have not been verified as part of this preview.
