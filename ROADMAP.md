# Roadmap

This is a direction for the project, not a promise or release schedule. Work should preserve private-by-default operation, explicit approval for external actions, and user control over learned information.

## Current: 0.1 alpha

- Stabilize installation, documentation and the fake-provider end-to-end path.
- Gather feedback on the console, skills, memory and learning controls.
- Verify supported model providers and optional integrations without requiring them for core use.

## Later

- **Windows LINE bridge:** an optional Windows companion for the official LINE integration, with clear pairing, local controls and approval-first sending.
- **Team bridge:** optional collaboration between separately permissioned assistant instances; no shared account data by default.
- **Model adaptation research:** evaluate local fine-tuning such as LoRA only with explicit dataset consent, inspectable training data, deletion controls and reproducible evaluation. Preference and skill learning do not require training model weights.
- Improve migration, backup/restore, accessibility and localization based on user feedback.

Priorities may change as the alpha is tested.
